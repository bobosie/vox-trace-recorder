# vox-record — 啟動測試錄製

## 何時用
使用者（PM/測試人員）想錄製一段測試操作時。錄製會捕捉：完整螢幕影片、麥克風語音（口述意圖）、所有點擊/輸入、網路 API 請求——供開發團隊產生可重現的自動化測試。

## 怎麼做
1. 先確認工具已安裝：`command -v vox-record`。若無 → 告訴使用者雙擊桌面的「vox-setup」安裝，或聯繫開發團隊。
2. 問使用者兩件事（若還沒說）：(a) 要測的網址；(b) 這次測什麼（一句話，當錄製名稱，例：「存款流程」）。
3. 執行錄製（背景啟動，讓使用者在跳出的瀏覽器手動操作）：
   `vox-record record --base-url <網址> --name <簡短名稱>`
   用 run_in_background 啟動，因為它會開瀏覽器 + 控制視窗等使用者操作。
4. 明確告訴使用者接下來做什麼：
   - 會跳出一個專用瀏覽器 → 像平常一樣操作（點按鈕、填表單、切頁面）
   - **邊做邊講話**，描述在做什麼、期望看到什麼（麥克風會錄）
   - 做完按控制視窗的 **Resume**（▶️綠色）結束
5. 錄完後：檔案會自動上傳到公司共用雲端硬碟給開發團隊，**使用者不用手動傳檔**。可告訴使用者「錄好了，已自動上傳」。

## 重點提醒
- **不要試圖自動操作瀏覽器**——這個工具的價值就是捕捉使用者「真實的手動操作」，Claude 只負責啟動 + 引導，實際操作由使用者本人做。
- 第一次錄製會問麥克風權限 → 請使用者按「允許」。
- 錄製名稱用簡短好懂的（會變成開發團隊看到的識別名）。
- 使用者若說「壞了 / 沒上傳」→ 檢查 `~/vox-pm-queue/failed/` 有無檔案、`~/vox-pm-queue/worker.log`，並回報開發團隊。

## 常見問答
- Q：要裝什麼嗎？A：只要雙擊過一次「vox-setup」就好，之後每次錄製工具會自動更新。
- Q：錄多久？A：沒限制，照平常測試節奏。
- Q：可以開多分頁嗎？A：可以，會自動記錄所有分頁。
